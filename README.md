# CPU Scheduling Simulator

A C++ project that simulates two CPU scheduling algorithms: First Come, First Served (FCFS) and Round Robin.

## Features
- Implements FCFS and Round Robin scheduling.
- Uses linked lists and queues to manage processes.
- Calculates process completion time and waiting time.
- Displays the process execution timeline and scheduling statistics.

## Technologies
- C++
- Data Structures: Linked Lists and Queues
